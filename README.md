# Monsieur Lavage Checy

Site vitrine — nettoyage automobile intérieur / extérieur et lustrage, à Checy (45430).

Page statique, sans build : `index.html` + `assets/`.

## Développement local

```bash
npx serve .
```

## Déploiement

Hébergé sur Vercel (déploiement automatique à chaque push sur `main`).
